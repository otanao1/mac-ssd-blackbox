# Issue #31 UI reference

`navigation.html`はユーザーが配置・操作を受入済みの合成モック、`comparison.html`は線とマーカーの比較・調整用モックの保存コピー。実DBや実測画面を含まない。HTML fragmentのため会話のプレビューまたはvisualizeのwrapperで表示する。

実装の正本はIssue #31。古いモックとの差異は以下の合意で上書きする。

- L1→L3→L2の3段とカード順。L3初期Single・3日、L2初期Multi・7日。
- GUIレビュー後の合意により、L2は7日・30日、L3は24時間・3日・7日・30日。古いモックの選択肢はこの合意で上書きする。
- 参考比較は薄い実線（不透明度40%を暫定値）。比較不可は細かい点線。正常は実線。
- 観測点は塗りつぶし丸／中抜き菱形。線より手前に描く。
- 子の記録なしは「サブフォルダ記録なし」。モックの0件表記は採用しない。
- END維持、期間単位の移動、データ更新・切替時の選択維持、メニューの初期化、再起動時は初期表示。
- Multiの省略された検索・ページ送り・行明細・L1棒・比較判定等は#22・#26の実装を維持する。

これらはモックの受入であり、本番Viewerの実画面受入ではない。
